לוח גאנט - תכנית עבודה שנתית · בית ספר גבים
=============================================

מה יש כאן
---------
index.html      - הלוח עצמו. תצוגה בלבד, מושך את הנתונים מהגיליון המפורסם בגוגל.
start-board.cmd - הפעלה בלחיצה כפולה (מומלץ). פותח את הלוח בדפדפן.
serve.ps1       - השרת המקומי הזעיר ש-start-board.cmd מפעיל. אין צורך לגעת בו.


איך פותחים את הלוח
------------------
לחיצה כפולה על start-board.cmd.

נפתח חלון שחור קטן (זה השרת המקומי) והדפדפן נפתח מיד עם הלוח.
משאירים את החלון השחור פתוח כל עוד מסתכלים בלוח, וסוגרים אותו בסיום.

למה צריך את זה: כשפותחים את index.html בלחיצה כפולה ישירה, גוגל חוסמת
את משיכת הנתונים מדפים שנפתחים ישירות מהמחשב (מגבלת אבטחה של הדפדפן,
לא משהו שניתן לתקן בקוד). start-board.cmd פותח בדיוק את אותו לוח בכתובת
מקומית (http://localhost:8731) שגוגל כן מאשרת. אין התקנה ואין אינטרנט
נדרש עבור השרת עצמו - רק PowerShell שמובנה בכל מחשב Windows.

אם מעלים את index.html לאתר בית הספר או לכל אחסון אינטרנטי, הוא יעבוד
שם בלחיצה רגילה על הקישור, בלי הקובץ הזה.


עדכון הנתונים
-------------
מעדכנים את הגיליון בגוגל (הוספה, שינוי או מחיקה של שורות אירוע),
ואז בלוח לוחצים על "רענון נתונים". הלוח נטען מחדש גם בכל פתיחה של הדף.

הלוח לא מאפשר לערוך אירועים - הגיליון הוא המקור היחיד.


מבנה הגיליון
------------
הלוח מזהה את שורת הכותרות לפי שמות העמודות, כך שאפשר להשאיר מעליה
שורת כותרת, שורת הנחיות ושורות ריקות. העמודות הנדרשות:

  שם האירוע · תאריך התחלה · תאריך סיום · תחום

עמודת ID אינה חובה. תאריכים נתמכים בכמה פורמטים: 2026-09-02 · 2.9.2026 · 02/09/2026.
שורה בלי שם או בלי תאריך תקין מדולגת, ומספר השורות שדולגו מוצג בהודעה בראש הלוח.
תחום שאינו ברשימת התחומים הקבועה יקבל שורה משלו בלוח בצבע ניטרלי.
